# Carpet Cleaning Template Collection

This directory contains landing page templates for carpet and upholstery cleaning services in various Melbourne suburbs. Each suburb has its own folder under `templates/carpet_cleaning/<suburb>/` containing:

- `<suburb>_carpet_cleaning.html` – the static HTML landing page.
- `README.md` – brief description and usage notes.

To add a new suburb, copy the folder structure, update the HTML content (address, phone, geo‑coordinates, and any suburb‑specific copy), and commit the changes.
